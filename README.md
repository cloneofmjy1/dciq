# DCIQ: domestic content calculator

Imperial Star Solar's domestic content calculator for solar PV projects, based on the IRS Notice 2025-08 safe-harbor percentages.

- **Calculator:** https://cloneofmjy1.github.io/dciq/
- **RE+ booth kiosk (lead capture):** https://cloneofmjy1.github.io/dciq/kiosk/

The results are estimates. They do not confirm credit eligibility for a project.

Each page is one self-contained HTML file. The source and tests live in Imperial Star's private workspace; this repository holds only the published copies.
